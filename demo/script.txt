#   port     5020 = slot 1 SCADA (FC 1,2,3,4,5,6,15,16), 5021 = slot 2 historian (FC 1,2,3,4); "-" for a pause
#   request  libmodbus call (unit id 1):  rb|rib|rr|rir ADDR N   wb ADDR 0|1   wr ADDR V   wbs ADDR b,b,..

#            raw HEX   the whole MBAP ADU, sent byte for byte on a plain socket
